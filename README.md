# Dr Ruth's Dental Clinic website

Single-page website for Dr Ruth's Dental Clinic, Virar West. Plain HTML, CSS and JavaScript, with no build step.

## Edit the content
Open `index.html` and edit the `CONFIG` block near the bottom (name, phone, WhatsApp number, hours, treatments, doctor details, gallery, reviews, FAQs). Colours are in the `:root` block in the CSS.

## Before publishing
- Confirm the clinic hours with the clinic (they are sample values).
- Add the doctor's name, qualifications and registration number.
- Replace the stock photos in `images/` with real clinic photos.
- Add real patient reviews only, with written permission.
- Have the doctor approve all text.

## Deploy
Works on GitHub Pages, Cloudflare Pages or Netlify. Deploy the repo root (`index.html` and the `images` folder together).
